SMILE GUIDANCE WEBSITE

Extract this ZIP before uploading or editing.

FILES
index.html - Page content
style.css - Responsive styling
app.js - Interactive UI
assets/reference.png - Required image asset
favicon.svg - Browser icon
vercel.json - Static hosting configuration

LOCAL PREVIEW
Open index.html in a browser. Keep all files and the assets folder together.

HOSTING
Upload the extracted contents to your static hosting project.
index.html must be at the website root. No build step or dependencies are required.
Vercel configuration is included in vercel.json.

This is a frontend UI. Sign-up, real listener availability, and live chat are not connected to a backend. Listener profiles are demonstration content.
